Write Mode Tool dodaje do każdej aplikacji na Macu akcje AI: tłumaczenie, odpowiedź na wiadomość, wysyłkę w Wiadomościach i dodanie terminu do kalendarza.

Nie wiesz, który masz? Menu Apple → „Ten Mac". Widzisz „Apple M…", wybierz pierwszy. Widzisz „Intel", wybierz drugi.

Co potrafi

Wszystkie akcje działają na zaznaczonym tekście. Nic nie dzieje się samo, wszystko sprawdzasz przed użyciem.

Wyślij w Wiadomościach

Wybierasz osobę ze swoich Kontaktów, a tekst otwiera się w aplikacji Wiadomości. Tak samo e-mail w aplikacji Mail.

Odpowiedz

Zaznacz wiadomość, wybierz ton (krótko, uprzejmie, stanowczo, zgoda, odmowa) i dostaniesz gotową odpowiedź.

Do kalendarza

Wyciąga terminy i zadania, rozumie „jutro" i „w piątek". Terminy trafiają do Kalendarza, zadania do Przypomnień.

Przetłumacz

17 języków, ostatnio użyty zawsze na górze. Tłumaczy znaczenie, a nie słowo w słowo.

Zapytaj o tekst

Pole na górze okna: pytasz o zaznaczony tekst albo prosisz o napisanie czegoś od zera.

Szukaj w internecie

Zaznaczone hasło otwiera się od razu w wyszukiwarce.

Praca i nauka

Slack lub Teams, pismo urzędowe, angielski biznesowy, komunikat commita, fiszki, quiz, trudne słowa.

Własne akcje

Sam piszesz polecenie dla AI, nadajesz nazwę i akcja ląduje w menu, np. „Zgłoszenie do Jiry".

Instalacja

Dwie minuty. Aplikacja nie jest podpisana przez Apple, więc przy pierwszym uruchomieniu macOS zapyta o zgodę.

  1. 1
    Pobierz plik .dmg, otwórz go i przeciągnij Write Mode Tool do folderu Programy.
  2. 2
    Kliknij aplikację prawym przyciskiem → Otwórz i potwierdź. Jeśli to nie pomoże, wpisz w Terminalu: xattr -cr "/Applications/Write Mode Tool.app"
  3. 3
    Zezwól na Dostępność (wklejanie wyniku), Automatyzację i Kontakty, gdy system zapyta.
  4. 4
    Wklej swój klucz API Anthropic (zdobędziesz go na console.anthropic.com) w oknie, które pojawi się przy pierwszym użyciu.
  5. 5
    Jeśli nie widzisz usług w menu prawego przycisku: Ustawienia systemowe → Klawiatura → Skróty klawiszowe → Usługi → Tekst i zaznacz Write Mode Tool.

Prywatność i koszty

Zaznaczony tekst jest wysyłany do Anthropic tylko wtedy, gdy użyjesz akcji AI, i tylko z Twoim kluczem API. Klucz jest zaszyfrowany na Twoim komputerze, a za zapytania płacisz Ty, na swoim koncie Anthropic. Nie używaj aplikacji do tekstów poufnych. Wiadomości i e-maile otwierają się jako szkic do sprawdzenia, chyba że sam włączysz w menu opcję wysyłania od razu.
